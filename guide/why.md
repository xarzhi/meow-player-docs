# 为什么做它 / 它适合谁

## 它是什么定位

一个**本地**播放器：不登录、不联网（除了查一下有没有新版本）、不抓取在线歌词、不上传任何东西。你放进去一个音乐文件夹，它把标签读出来建库，就这样。

界面用 GPUI 手写 —— 就是 Zed 编辑器那套 GPU 加速 UI 框架，所以它看起来是「原生桌面程序」而不是「套壳网页」，也不需要在后台常驻一个浏览器内核。

## 适合你，如果

- 音乐都在本地硬盘（无损、整轨、各种稀奇格式），想要一个**扫描快、标签读得全**的库；
- 有外置 DAC / 声卡，需要**独占输出**按文件采样率直出；
- 想要**桌面歌词**（尤其希望能贴在任务栏上，不占桌面空间）；
- 喜欢**常驻小窗**（迷你播放器），一边干活一边看歌词、随手切歌；
- 在意**轻度**：安装包 57MB、单进程、空闲 50MB 上下、不需要装任何运行时；
- 想要**全局快捷键**和**托盘**，戴着耳机切歌不用切窗口。

## 可能不适合你，如果

- 你需要**在线音乐源**（它的设计前提就是「本地优先」，没有接任何在线曲库）；
- 你用的是 macOS / Linux（现在只支持 Windows —— WASAPI、托盘、全局键盘钩子、窗口材质都是 Win32 那套）；
- 你依赖**独占输出时的频谱**（那条路上暂时取不到样点，见[频谱](/guide/features#频谱)一节的说明）；
- 你需要**自动静默升级**（现在只做「提示 + 跳转下载」，不会自己替换正在运行的 exe —— 这是有意为之：安装版在 `Program Files` 下，替换要提权，而且升级过程会杀掉正在播放的进程）。

## 和常见方案比

| | Meow Player | Electron 系播放器 | 传统原生播放器 |
| --- | --- | --- | --- |
| 运行时依赖 | 无 | 带 Chromium | 一般无 |
| 进程数 | 1 | 3~5 | 1 |
| 安装包 | ~57 MB | 100~200 MB | 通常更小 |
| 界面 | GPUI 直接 GPU 绘制 | 网页技术 | 各平台原生控件 |
| 扩展性 | 源码即全部 | 插件生态成熟 | 视具体项目 |

> 这张表只说形态，不比谁更好用 —— 音质、格式支持、生态这些各有取舍。

## 已知限制

- **只支持 Windows**；
- 独占输出模式没有频谱；
- 更新检查需要能访问 Gitee（离线时会静默失败，不影响使用）；
- 歌词匹配依赖歌词文件或音频内嵌歌词，**没有做在线歌词搜索**；
- 安装包体积还有优化空间（当前用的是 release profile 的体积优先设置，但没做到极致）。
