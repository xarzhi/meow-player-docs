# 安装与上手

## 安装

1. 到 [Gitee 的发行版页面](https://gitee.com/xarzhi/meow-player/releases) 下载最新的 `MeowPlayer_v{版本}_setup.exe`；
2. 双击运行，安装程序是**图形界面**的，默认装到当前用户目录（不需要管理员权限）；
3. 如果之前装过，安装程序会**自动沿用上次的安装目录**（读注册表里的 `InstallLocation`）。

安装包会创建开始菜单和桌面快捷方式，并注册卸载项（Windows「应用和功能」里能看到，版本号取自安装包本身）。

## 第一次使用

1. 打开程序 → 进「设置 · 通用 · 音乐库」→ 添加你的音乐文件夹；
2. 程序开始扫描（读标签 + 解封面，都在后台线程），进度显示在设置页；
3. 扫完之后左侧「歌曲 / 专辑 / 音乐家」里就有内容了，双击即播放。

## 数据放在哪

| 内容 | 位置 |
| --- | --- |
| 配置（`config.json`） | `%APPDATA%\Meow Player\` |
| 音乐库数据库（`meow.db`）、封面缓存、壁纸 | 安装目录（便携版则跟着 exe） |

安装目录里那个 `.meow-data` 标记文件用来判定「这份是便携版，数据放 exe 旁边」。
