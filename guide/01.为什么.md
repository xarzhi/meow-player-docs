# 为什么做它

## 定位

我想做一款**操作简单**、**内存占用低**、**运行速度快**的**本地音乐播放器**。

在观察了众多本地播放器后，结合自己的感想，创作了 Meow Player。

界面用 `Rust` + `GPUI` 手写，**不依赖浏览器内核，没有 WebView，GPU 渲染**。

---

## 和其他框架相比，为什么选 Rust + GPUI

市面上的桌面音乐播放器，绝大多数都可以归到下面几类技术路线里。把它们和 Meow Player 放一起比，差距一眼就能看出来：

| 技术路线 | 代表作品 | 启动速度 | 内存占用 | 依赖体积 | 卡顿情况 |
| --- | --- | --- | --- | --- | --- |
| **Electron（Web 技术）** | 多数网易云/QQ 音乐桌面端、各类网盘客户端 | 慢（要拉起整个 Chromium） | 高（常驻 300MB+） | 巨大（内核自带） | 滚动/动画偶有掉帧 |
| **Tauri（WebView + Rust 外壳）** | 部分新兴客户端 | 中等 | 中（仍带 WebView） | 中 | 受系统 WebView 性能制约 |
| **Qt / GTK（C++）** | 老牌本地播放器（如 foobar2000 生态、部分播放器） | 快 | 低 | 小 | 低（但开发/维护门槛高） |
| **Rust + GPUI** | **Meow Player** | **极快** | **极低**<br>最低只有30Mb | **极小** | **极低** |

具体到体验上，Meow Player 的优势是实打实的：

![image-20261015145513858](/guide/image-20261015145513858.png)

### 1. 不背浏览器内核，轻得像个"原生小程序"

Electron 这类方案，本质上是在你的电脑里塞了一个完整浏览器，只为了画一个界面。这带来三重代价：

- **启动慢**：每次打开都要等 Chromium 初始化；
- **内存高**：哪怕只是听歌，后台也常驻几百 MB；
- **体积大**：安装包动辄上百 MB，大头全花在了"画界面的引擎"上。

Meow Player 直接用 GPUI 在 GPU 上画界面，**界面、音频、数据库都在同一个 Rust 进程里**。没有 WebView、没有 JS 运行时，启动几乎瞬间完成，内存占用压到最低。

### 2. Rust 的可靠与性能，是"写出来的"而非"调出来的"

Rust 在编译期就消灭了空指针、数据竞争、内存泄漏这三大类臭名昭著的 Bug。对播放器这种**长时运行、高频操作**的软件来说，这意味着：

- **不会越跑越卡**：内存安全由编译器保证，不存在"听两小时歌后慢慢变卡"的经典问题；
- **崩溃少**：绝大多数错误在编译阶段就被拦下，而不是运行时才崩溃；
- **性能稳定**：零成本抽象 + 无 GC 停顿，音频解码、FFT 频谱、封面缩放这些重活，跑得又快又稳。

### 3. 极致性能，靠的是"抠细节"

这个项目对性能的在意程度，从构建配置就能看出来——依赖一律按 `-O2` 编译，release 版开 `lto` 并 `strip` 掉符号。界面是**每帧现搭元素树再画**，全屏播放页还要在后台线程转封面位图，实测整窗口一帧 26ms 左右，转圈和逐字歌词依旧顺滑。

## 软件内有哪些实用功能

Meow Player 不是"能放歌就行"的玩具，而是一个功能完备的播放器。下面挑重点说。

### 🎵 音乐库：扫描、建库、智能整理

- **多文件夹递归扫描**：一次扫描多个目录，自动读标题 / 艺术家 / 专辑 / 时长 / 内嵌封面与歌词；
- **拼音排序**：中文歌曲按拼音首字母分组排序，列表清爽易找；
- **音质徽标**：一眼看出每首歌的音质档次；
- **标签编辑器**：右键即可改标题 / 艺术家 / 专辑 / 流派，**先写回文件、成功了才改数据库**，绝不出现"界面新名字、文件旧名字"的错乱。

### 🎧 播放：不止"能出声"，而是"怎么出都好听"

- **双输出通道**：共享输出走系统混音，独占输出直接用 WASAPI（绕开混音、按文件采样率直出）；
- **10 段均衡器**：31Hz ~ 16kHz 每段 ±12dB，自写双二阶滤波器，还能存成自定义音效；
- **3D 环绕音**：声像在左右声道间规律平移，等功率 pan 定律保证全程响度不忽大忽小；
- **智能过渡**：自动切歌时**跳过非人声的头尾**——通过立体声中置掩蔽把人声从伴奏里滤出来，当前这歌最后一句唱完就切下一首，下一首从第一句人声起播。器乐前奏尾奏、静音头尾统统不放。

### 📝 歌词：从内嵌到桌面，层层到位

- 支持 `.lrc` 等格式与内嵌歌词；
- 全屏页**逐行滚动 + 逐字填充**，点哪句跳哪句；
- **独立桌面歌词窗口**：可锁定、可贴任务栏，按钮颜色跟随系统主题；
- **迷你播放器**：封面 + 歌名 + 当前歌词（长句把当前字滚到中间），**播放进度直接画成窗口边框**，按住封面拖窗口。

### 📊 频谱：真 FFT，不是摆样子

全屏页进度条上方那排柱子，是**真的做了 FFT**——挂在音频源上的取样器 → 手写 radix-2 FFT → 对数分频。柱数、粗细、圆角、颜色、开关全都能调。这跟某些播放器里"循环播放一张预设动画"的假频谱，是两码事。

### 🖥 界面与系统集成：像个"正经软件"

- **主题**：亮 / 暗 / 跟随系统；窗口材质支持云母 / 亚克力 / 经典；还能设壁纸；
- **系统托盘**：托盘菜单、关闭到托盘、单实例运行；
- **全局快捷键**：低层键盘钩子，**只观察不抢键**；
- **任务栏进度**、**圆角窗口**等 Windows 特性，全部手写 FFI 接入，没引入多余封装；
- **定时关闭**：N 分钟后暂停，或"唱完当前这首停"；
- **多语言**：中文、English、한국어 三语切换。

### 🔒 隐私与安全：完全本地

- **不联网、不依赖任何在线服务**：所有数据都在本地，没有账号、没有上传、没有广告；
- **删除进回收站**：右键"删除文件"走的是系统回收站，误删了能捞回来；
- **更新检查**：启动时查 Gitee 发行版，有新版弹窗提示，频率可调，还能"跳过此版本"。

---

Meow Player 想证明一件事：**一款本地音乐播放器，本可以又快又轻，又好看又好用**——而不是靠塞一个浏览器内核、堆一堆在线服务来撑场面。它用 Rust 的可靠、GPUI 的性能，加上一个又一个"抠细节"的实用功能，做到了这一点。
