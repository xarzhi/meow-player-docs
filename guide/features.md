# 功能一览

这一页把每个功能都过一遍，包括一些实现上的取舍 —— 方便你判断它是不是你要的东西。

## 音乐库

![主界面](/shots/main.png)

- **多目录扫描**：可以添加多个音乐文件夹，递归遍历（`walkdir`），后台线程跑，不卡界面；
- **读标签**：标题、艺术家、专辑、时长、内嵌封面、内嵌歌词（`lofty`）。标签缺了就退回文件名；
- **按拼音排序**：中文歌名/歌手按拼音排序，列表按**首字母分组**（A / C / D …），找歌不用翻；
- **音质徽标**：可选显示 Hi-Res / CD / SQ / HQ，直接看出这首歌是什么规格；
- **三种视图**：歌曲、专辑、音乐家；专辑和音乐家可以点进去看详情列表；
- **搜索**：标题 / 艺术家 / 专辑 / 拼音首字母都能搜，输入即搜（带防抖）。

![专辑页](/shots/album.png)

## 播放

- **两种输出方式**：
  - *共享输出*（`rodio`）：走系统混音，切歌不断音，可以在播放中调音量、和别的程序一起出声；
  - *独占输出*（直接对接 WASAPI）：绕开系统混音，按文件采样率直出，适合有外置 DAC 的场合；
- **播放模式**：顺序 / 单曲循环 / 随机（播放条左侧按钮切换，有 tooltip 提示当前模式）；
- **进度条**：点一下或拖动都能跳转（拖动时进度跟手，松手才真的跳）；播放位置同步到**任务栏进度**；
- **音量**：播放条右下角的音量按钮，点开是滑块；
- **上一首 / 播放暂停 / 下一首**：播放条中间三个按钮，也支持全局快捷键。

## 均衡器

![均衡器](/shots/equalizer.png)

- **10 段**：31Hz / 62Hz / 125Hz / 250Hz / 500Hz / 1k / 2k / 4k / 8k / 16k，每段 **±12dB**；
- **自己写的双二阶（biquad）滤波器**，不是外挂一个均衡器库；
- 一排预设（平坦 / 摇滚 / 重金属 / 流行 / 爵士 / 古典 / 清晰人声 / 低音增强 / 高音增强 / 电子），**可以把自己调好的存成自定义音效**；
- 改动立刻生效，不用重开音频流、不打断播放。

## 歌词

![全屏播放页](/shots/player-fullscreen.png)

- 支持常见的歌词文件格式（`.lrc` 等），也读音频文件里的**内嵌歌词**；
- **全屏播放页**：左边封面、右边歌词。当前句**大一号 + 加粗 + 最亮**，相邻的行按距离依次变暗；**逐字填充**（唱到哪个字，那个字之前的部分变亮色）；点某一句可以直接跳到那一句；
- 歌词列表可以上下滚动，鼠标滚轮和滑块都行；

| ![桌面歌词](/shots/desktop-lyrics.png) | ![贴任务栏](/shots/任务栏歌词.png) |
| --- | --- |
| 桌面歌词（独立小窗） | 贴任务栏形态 |

- **桌面歌词**：一个**独立的置顶小窗**，显示当前句 + 下一句。可以锁定（锁定后鼠标穿透、不再挡操作）；字号 / 颜色 / 文字描边都能调；
- **贴任务栏形态**：把歌词直接压到任务栏上，只占任务栏那一条的高度；歌词太长会跟着唱到的位置横向滚动。锁定 / 收起 / 关闭三个按钮的颜色**可以跟随系统亮暗主题**（亮色任务栏上自动用黑图标）。

## 频谱

全屏播放页进度条上方那条竖着跳的频谱，是**真的从音频流取样做 FFT 算出来的**，不是假的随机动画：

- **取样点挂在「解码之后、进声卡之前」的音频源上**：音频线程老老实实转发每个样点，顺手把「一帧的平均值」塞进环形缓冲；界面每帧读一次来算。两边谁也不等谁，**播放线程不会被界面卡住**；
- **手写 radix-2 FFT**（1024 点）+ **汉宁窗**（不加窗频谱会漏得厉害），没有为这个功能引 FFT 依赖；
- **对数分频**：柱子按对数分布覆盖 **40Hz ~ 14kHz**，低频几根、高频一根，和听感一致；
- 可调：**显示开关、柱子数量（24~96）、粗细（2~10px）、圆角或平角、颜色**（调色盘 + 常用色块）；关掉总开关时下面几项会**收起来**（带动画的折叠）；
- **平滑方式**：上升快（0.55）、回落慢（0.16），跳起来才有弹性；安静时是最矮的一条细线，暂停直接归零。

> 一个诚实的限制：**独占输出模式没有频谱** —— 那条路直连声卡，不经过 `rodio` 的音频源，取不到样点。

## 迷你播放器

![迷你播放器](/shots/mini-player.png)

从底部播放条右边的「更多 → 迷你播放器」打开，是一个 **360×82 的独立小窗**：

- **左**：当前歌曲封面（没有封面或没在播放时显示程序 logo）；
- **中**：上面歌名，下面当前歌词行 —— 同样**逐字填充**，而且**长句会跟着唱到的位置横向滚动，把正在唱的那个字停在中间**；
- **右**：上一首 / 播放暂停 / 下一首；
- **进度**：可以选**环形**（进度沿窗口四条边顺时针走，拐角是真正的圆弧）或**底部一条直线**，颜色可调；
- **模糊背景**：可以选把封面当背景（缩到很小再放大，等效磨砂），而且**按封面原比例**裁切铺满、比窗口大一圈；
- **交互**：按住封面可以**拖动窗口**（光标会变成手的形状）；点进度条可以**跳转**（环形会按周长换算，点哪跳哪）；
- **打开位置**：左上 / 右上 / 左下 / 右下 / **顶部中央** / **底部中央** / **上次关闭时位置**；顶部离屏幕边缘 100px，底部在任务栏上面 50px；
- **与主窗口的关系**：默认打开迷你播放器就**把主窗口收起来**（右上角的按钮能换回来），也可以设置成**两个窗口一起显示**。

## 界面与外观

![设置](/shots/setting.png)

- **主题**：亮色 / 暗色 / 跟随系统；
- **窗口材质**：云母（Mica）、亚克力（Acrylic）、经典（不透明），另有「失焦是否保持模糊」的开关；
- **壁纸**：可以放自己的壁纸，配合材质做成半透明观感；
- **字体**：系统默认或指定字体；
- **侧栏**：可以收起成只剩图标（带宽度过渡动画）；
- **自定义 tooltip**：播放条上的按钮 hover 有提示气泡，显示在按钮**正上方**（gpui 自带的 tooltip 只能跟鼠标、没有方向参数，所以这部分是自己封装的，方向可传）；
- **设置页**分成 通用 / 外观 / 歌词 / 均衡器 / 快捷键 / 关于 六页，改完立刻生效并写进 `config.json`。

## 系统集成

- **托盘**：托盘图标 + 菜单（播放控制、桌面歌词开关、退出）；
- **全局快捷键**：用低层键盘钩子实现，程序在后台也能用；**只观察不抢键**，不会影响别的程序；按键可以自己改；
- **单实例**：重复启动不会开第二个窗口，而是把已有窗口叫到前面；
- **关闭行为**：可选「退出程序」或「最小化到托盘」；
- **任务栏进度**：播放进度直接显示在任务栏图标上；
- **窗口圆角**：用 Win11 的 DWM 圆角（合成器绘制、**带抗锯齿**），Win10 上回退到系统区域裁剪。

## 更新检查

- 启动时查一次 Gitee 上的最新发行版（默认**每次启动都查**，只隔 10 分钟，防止手抖连开十次）；
- 比本地版本新就**弹窗提示**（显示版本号和 Release 说明），点「去下载」打开发行版页面；
- 可以「跳过此版本」，也可以把频率改成**每天首次启动检测**或**不自动检测**；
- 关于页还有「检查更新」按钮，可以随时手动查（无视节流）；
- 只提示，**不会自动替换正在运行的程序** —— 升级交给安装包自己。
