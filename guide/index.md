# 这是什么

**Meow Player** 是一个 Windows 上的**本地音乐播放器**，用 Rust 写、界面基于 GPUI（Zed 编辑器那套 GPU 加速 UI 框架）。它不联网、不依赖任何在线服务：扫描你本地的音乐文件夹，读标签建库，然后就是播放、看歌词、调音。

> 目前只支持 Windows（用到了 WASAPI、Win32 的托盘 / 快捷键 / 窗口材质）。

## 主要能力

| 方面 | 说明 |
| --- | --- |
| 音乐库 | SQLite（`rusqlite`）存库；扫描时用 `lofty` 读标签；封面单独缓存成缩略图 |
| 播放 | `rodio` 走系统混音；独占模式直接用 WASAPI，绕开系统混音、按文件采样率输出 |
| 均衡器 | 自写双二阶滤波器的 10 段均衡，可保存成自定义音效 |
| 歌词 | 支持 `.lrc` 等格式；全屏页逐行滚动 + 逐字填充；桌面歌词窗口 |
| 频谱 | 从解码后的音频流取样、手写 radix-2 FFT、对数分频 |
| 界面 | 亮 / 暗 / 跟随系统；云母、亚克力、经典三档窗口材质；壁纸 |
| 系统集成 | 托盘、全局快捷键、任务栏进度、单实例、关闭到托盘 |
| 更新 | 启动时查 Gitee 上的发行版，有新版弹窗提示（可关闭） |
