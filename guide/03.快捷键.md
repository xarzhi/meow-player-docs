# 快捷键

软件内置了很多使用的快捷键

## 全局快捷键

| 快捷键       | 作用      |
| ------------ | --------- |
| `Ctrl+Space` | 播放/暂停 |
| `Ctrl+Left`  | 上一首    |
| `Ctrl+Right` | 下一首    |
| `Ctrl+Up`    | 音量加    |
| `Ctrl+Down`  | 音量减    |



## 程序内快捷键

| 快捷键           | 作用         |
| ---------------- | ------------ |
| `Ctrl+Alt+Lef`   | 上一张壁纸   |
| `Ctrl+Alt+Right` | 下一张壁纸   |
| `Ctrl+A`         | 全选歌曲     |
| `Ctrl+F`         | 搜索         |
| `Esc`            | 清空搜索     |
| `F11`            | 切换全屏     |
| `Ctrl+T`         | 切换明暗主题 |
| `Ctrl+W`         | 开关壁纸     |
| `F5`             | 刷新音乐库   |
| `A-Z/0`          | 跳到字母分组 |
